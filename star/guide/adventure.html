冒险模式 (RPG 文字冒险) ​

冒险模式是一个以 AI 为游戏主持人 (DM) 的像素奇幻文字冒险游戏，是对 AI 对话能力的创造性应用。

背景设定 ​

  • 世界：「艾瑟兰」— 充满魔法、怪物和遗迹的像素奇幻世界
  • DM 角色：「命运织者」— 用第二人称"你"叙述，营造沉浸式游戏体验
  • 交互方式：AI 生成叙事 → 自动提取选项 → 玩家选择 → 骰子判定 → AI 续写

系统 Prompt 结构 ​

DM 的核心行为约束通过 system prompt 定义：

ts
const DM_SYSTEM_PROMPT = `你是一个像素奇幻世界的游戏主持人 (DM)，名叫「命运织者」。

【叙事规则】
- 用第二人称"你"叙述，营造沉浸感
- 每次回复先描述场景/结果（50-100字），再给出后续发展
- 使用丰富的感官描写（视觉、听觉、嗅觉）
- 每次回复末尾用【选项】标记列出 2-4 个行动选项，每行一个
  例如：
  【选项】
  1. 走进小镇
  2. 询问路人
  3. 观察四周

【数值追踪】
- 每轮回复用【状态】HP:20/30 MP:10/15 Lv:2 金币:50 格式标记
- 物品变化用【装备】获得 生锈的铁剑 或【获得】金币×10
- 战斗用描述性语言，无需复杂计算
- 玩家升级时用【升级】Lv.3 标记
- 玩家位置变化用【地点】烬石镇 标记

【世界设定】
- 世界名为「艾瑟兰」，充满魔法、怪物和遗迹
- NPC 对话用「」引用
- 保持史诗奇幻风格，偶尔加入幽默`

const itemCategory = (item: string): string => {
  if (/剑|斧|弓|矛|匕首|锤|刃|枪/.test(item)) return '⚔️'

  return '📦'
}

D20 骰子系统 ​

玩家行动附带 d20 (1-20) 判定，增加随机性和策略性：

ts
const rollD20 = (): number => {
  return Math.floor(Math.random() * 20) + 1
}

// 行动时
const onChoice = (choice: string) => {
  const roll = rollD20()
  const rollText = roll >= 10 ? '成功' : '失败'

  addMessage({
    type: 'player_action',
    content: choice,
    roll   // 骰子结果展示在消息旁
  })

  // 将骰子结果附加到发送给 AI 的消息中
  const enhancedText = `[骰子: ${roll}/20 - ${rollText}] ${choice}`
  sendToAI(enhancedText, true)
}

骰子结果与"成功/失败"标签一同展示在玩家行动消息旁，AI 会根据结果调整叙事走向（成功 = 顺利、失败 = 意外）。

消息类型 ​

ts
interface AdventureMessage {
  id: number
  type: 'narration' | 'player_action' | 'system'
  content: string
  roll?: number  // 仅 player_action 有
}
类型说明展示样式
narrationAI 叙事（过滤标记后的正文）左侧，像素气泡
player_action玩家行动 + 骰子结果右侧，带骰子图标
system系统通知居中，灰色文字

选项解析 ​

AI 每次回复末尾用 【选项】 标记提供 2-4 个行动选项，前端自动解析为可点击按钮：

ts
// 从 AI 回复中自动提取选项
const finishAIResponse = (content: string) => {
  // 正则匹配【选项】块
  const choiceMatch = content.match(/【选项】\n?([\s\S]*?)(?=\n【|$)/)

  if (choiceMatch) {
    const choiceLines = choiceMatch[1]
      .split('\n')
      .map(l => l.trim())
      .filter(l => /^\d+[\.\、]/.test(l))   // 匹配 "1. " 或 "1、"
    choices.value = choiceLines
  }

  // 过滤标记行，展示干净叙事
  const cleanContent = content
    .replace(/【选项】[\s\S]*?(\n【|$)/g, '$1')
    .replace(/【状态】.+?(\n|$)/g, '')
    .replace(/【装备】.+?(\n|$)/g, '')
    // ...
    .trim()

  addMessage({ type: 'narration', content: formatContent(cleanContent) })
}

状态解析 ​

AI 回复中的标记由前端自动解析，更新 HUD 面板：

ts
const parseAll = (text: string) => {
  // 【状态】HP:20/30 MP:10/15 Lv:2 金币:50
  parseStatus(text)

  // 【装备】获得 生锈的铁剑 → 加入背包
  // 【获得】金币×10
  parseInventory(text)

  // 【地点】烬石镇 → 更新位置
  parseLocation(text)
}

const parseStatus = (text: string): boolean => {
  const m = text.match(/【状态】(.+?)(?=\n|$)/)
  if (!m) return false
  // 正则提取 HP/MP/Lv/金币 → 更新 state.player
}

const parseInventory = (text: string): boolean => {
  // 正则提取【装备】和【获得】→ 去重后 push 到 state.inventory
}

const parseLocation = (text: string): boolean => {
  const m = text.match(/【地点】(.*?)(?=\n|$)/)
  if (m) state.location = m[1].trim()
}

快捷动作 ​

底部提供 5 个快捷动作按钮，一键触发常见操作：

动作发送的文本特效
攻击我要攻击附近的敌人！斩击动画

动作特效 ​

  • 攻击：屏幕闪现 → 3 道青色斩击线交错划过 → 火花粒子爆散
  • 调查：3 个同心圆波纹扩散 → 🔍 图标弹跳

交互流程 ​

1. 场景选择弹窗
   └─→ 输入冒险者名称 / 选择预设场景
       └─→ resetState() 初始化 HUD + 消息上下文
           └─→ sendToAI(scene.initialPrompt) 请求开场叙事

2. 游戏循环
   ┌──────────────────────────────────────┐
   │ AI 回复                               │
   │   ├─→ 过滤标记 → 展示叙事             │
   │   ├─→ 解析【选项】→ 渲染选项按钮       │
   │   └─→ 解析【状态/装备/地点】→ 更新 HUD │
   │                                      │
   │ 玩家行动                               │
   │   ├─→ 点击选项 / 快捷动作按钮           │
   │   ├─→ D20 骰子判定                    │
   │   └─→ sendToAI(增强后的文本)           │
   │                                      │
   │ 循环 ↑                                │
   └──────────────────────────────────────┘

3. 离开冒险
   └─→ endGame() → router.push('/intelligence')

性能考虑 ​

  • 消息上下文管理：每次请求携带完整消息历史，确保多轮对话连贯性
  • 选项防抖：isAnswering 状态锁防止快速点击
  • 滚动：新消息到达自动滚动到底部
  • 中断支持：可随时中止 AI 生成，AbortController.abort()
  • 环境粒子：CSS 动画实现的浮动粒子背景，12 个粒子不同延迟/速度/大小
