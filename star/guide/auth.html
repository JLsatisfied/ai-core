RSA 加密流程 ​

1. 客户端请求公钥    → GET /aicg/user/publicKey
2. 服务端返回公钥     → { key: "-----BEGIN PUBLIC KEY-----..." }
3. 客户端用公钥加密密码 → node-forge.pki.publicKeyFromPem(key).encrypt(password)
4. 发送加密后的密码    → POST /aicg/user/login { account, password: encrypted }
5. 服务端用私钥解密验证
6. 返回 token         → 存储到 localStorage + Pinia

实现代码 ​

ts
import forge from 'node-forge'

async function login(account: string, password: string) {
  // 1. 获取公钥
  const { key } = await userApi.publicKey()

  // 2. RSA 加密密码
  const publicKey = forge.pki.publicKeyFromPem(key)
  const encrypted = forge.util.encode64(publicKey.encrypt(password))

  // 3. 发送登录请求
  const result = await userApi.login({ account, password: encrypted })

  // 4. 存储 token（支持30天免登录）
  store.setToken(result.token, keepLoggedIn)
}

Token 管理 ​

ts
// store/index.ts
export const useStore = defineStore('user-storeId', {
  state: () => ({
    token: localStorage.getItem('token') as string | null,
    freeEntry: localStorage.getItem('freeEntry') as string | null,
  }),
  actions: {
    setToken(newToken: string, persist = false) {
      this.token = newToken
      if (persist) {
        // 30天免登录标记
        localStorage.setItem('freeEntry', 'true')
      }
      localStorage.setItem('token', newToken)
    },
    clearToken() {
      this.token = ''
      this.freeEntry = ''
      localStorage.removeItem('token')
      localStorage.removeItem('freeEntry')
    },
  },
})

退出登录 ​

退出登录时调用服务端接口拉黑当前 token + 本地清理：

ts
const outLogin = () => {
  userApi.logout().then(() => {
    useStore().clearToken()
    router.push('/')
  })
}

路由守卫 ​

ts
router.beforeEach((to) => {
  NProgress.start()
  const store = useStore()
  // 未登录访问需要鉴权的页面 → 跳转首页
  if (!store.token && to.path !== '/') {
    ElMessage.warning('请先登录')
    return { name: 'home' }
  }
})

Axios 拦截器 ​

ts
// 请求拦截器 — 自动附加 token
http.interceptors.request.use((config) => {
  const token = localStorage.getItem('token')
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})

// 响应拦截器 — 401 自动跳转登录
http.interceptors.response.use(
  (res) => res,
  (err) => {
    if (err.response?.status === 401) {
      store.clearToken()
      router.push('/')
    }
    return Promise.reject(err)
  },
)
