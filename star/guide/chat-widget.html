客服小部件 ​

可配置参数 ​

ts
interface ChatConfig {
  welcomeText: string     // 欢迎寄语
  signature: string       // 署名 (显示在 AI 消息下方)
  title: string           // 称号 (客服窗口标题)
  techBrand: string       // 工坊印记 (底部品牌文字)
  themeColor: string      // 主题色
  apiKey: string          // DeepSeek API Key
}

嵌入方式 ​

配置完成后，点击"召唤符石"按钮生成嵌入代码：

html
<script>
window.BotConfig = {
  appId: "your-app-id"
};
(function () {
  var scriptElement = document.createElement("script");
  scriptElement.src = "https://your-domain.com/js/kefuButton.js";
  document.head.appendChild(scriptElement);
})();
</script>

将此标签粘贴到任意网页的 <head> 或 </body> 前，即可在页面右下角出现客服按钮。

DeepSeek API 配置 ​

客服小部件支持自定义 DeepSeek API 参数：

ts
interface DeepSeekConfig {
  apiKey: string          // API 密钥
  model: string           // 模型 (deepseek-chat / deepseek-coder / etc.)
  temperature: number     // 温度 (0-1, 越低越确定)
  maxTokens: number       // 最大 token 数 (100-4000)
  topP: number           // 智慧广度 (0-1)
  stream: boolean         // 逐字显现 (流式输出)
}

配置通过弹窗表单修改，实时生效。

Markdown 消息渲染 ​

客服消息支持完整的 Markdown 语法：

消息渲染使用 markdown-it 在客户端执行，不依赖后端。

流式输出流程 ​

用户发送消息
  │
  ▼
fetch() → POST https://api.deepseek.com/v1/chat/completions
  │         Authorization: Bearer {apiKey}
  │
  ▼
ReadableStream.getReader().read()
  │
  ├─→ stream: true  → SSE 逐字追加到消息气泡
  │
  └─→ stream: false → 等待完整响应后一次性显示
  • 流式模式：通过 Reader API 逐块读取，解析 SSE 格式，实时代码高亮
  • 非流式模式：完整响应后 JSON.parse，Markdown 渲染

停止与重置 ​

ts
// 停止生成
const stopTyping = () => {
  controller.value?.abort()  // 中止 fetch 请求
  isTyping.value = false
  // 追加"回复已停止"标记
}

// 重置对话
const resetConversation = () => {
  if (controller.value) controller.value.abort()
  messages.value = [{ type: 'ai', content: chatConfig.welcomeText }]
}

技术要点 ​

  • 配置持久化：调用后端 addCustomerService 接口保存配置
  • API Key 安全：API Key 存储在客户端的 chatConfig 中，直接调用 DeepSeek API
  • 主题色动态绑定：通过 :style 动态绑定主题色到所有 UI 元素
  • 移动端预览：聊天窗口固定 375×667 像素，模拟移动端视口
  • 图像生成：支持 AI 图片生成（通过 queryImg 接口）
