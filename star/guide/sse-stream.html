SSE 流式请求 ​

冒险纪元 使用 SSE (Server-Sent Events) 实现 AI 对话的实时流式输出。针对不同的 AI 模型，有两套独立的流式处理逻辑。

技术方案 ​

使用 @microsoft/fetch-event-source 库，它提供了比原生 EventSource 更好的控制能力：

  • 支持 POST 请求（原生 EventSource 仅支持 GET）
  • 自定义请求头（Content-Type, Authorization）
  • 请求体携带 JSON 数据
  • 错误处理和自动重连
  • 手动中止请求（AbortController）

DeepSeek 流式请求 ​

端点与模块 ​

POST /aicg/deepseekMoudle
Body: { text: requestContent[], moduleId: 'deepseek-v4-flash' | 'deepseek-reasoner' }

核心实现 ​

ts
import { fetchEventSource } from '@microsoft/fetch-event-source'

// 维护对话上下文（用于多轮对话）
const requestContent: { role: string; content: string }[] = []

async function sendToDeepSeek(userMessage: string, moduleId: string) {
  // 1. 添加用户消息到上下文
  requestContent.push({ role: 'user', content: userMessage })

  // 2. 创建 AbortController 用于中断
  ctrl.value = new AbortController()

  // 3. 添加空消息占位
  const msgIndex = allText.length
  if (moduleId === 'deepseek-reasoner') {
    allText.push({
      userText: userMessage,
      adminContent: { adminText: '', isShow: true },
      thinkContent: { thinkText: '', status: '1', isShow: true, isOpen: false }
    })
  } else {
    allText.push({
      userText: userMessage,
      adminContent: { adminText: '', isShow: true }
    })
  }

  // 4. 发起 SSE 流式请求
  fetchEventSource(BASE_URL + 'deepseekMoudle', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ text: requestContent, moduleId }),
    signal: ctrl.value.signal,
    openWhenHidden: true,  // 页面隐藏时保持连接

    onmessage(ev) {
      if (!ev.data || ev.data === '[DONE]') return
      const res = JSON.parse(ev.data)

      // ---- 推理内容 (仅 Reasoner 模式) ----
      if (res.choices?.[0].delta.reasoning_content) {
        thinkContent += res.choices[0].delta.reasoning_content
        // Worker 渲染思考内容为 HTML
        renderInWorker(thinkContent).then(html => {
          msg.thinkContent!.thinkText = html
        })
        msg.thinkContent!.status = '1'        // 思考中
        msg.thinkContent!.isOpen = true       // 默认展开
        msg.adminContent.isShow = false       // 隐藏回答区域
      }

      // ---- 正式回答 (所有模式) ----
      if (res.choices?.[0].delta.content) {
        markdownContent += res.choices[0].delta.content
        // Worker 渲染回答内容为 HTML
        renderInWorker(markdownContent).then(html => {
          msg.adminContent.adminText = html
        })
        msg.adminContent.isShow = false       // 流式期间隐藏加载动画
      }

      // 服务端降级返回纯文本消息
      if (res.message) {
        msg.adminContent.adminText = res.message
      }
    },

    onclose() {
      // 流正常关闭 → 保存对话记录
      markdownContent = ''
      thinkContent = ''
      isAnswering.value = false
      saveMessage()  // 持久化对话
    },

    onerror() {
      // 连接异常
      if (moduleId === 'deepseek-reasoner') {
        msg.thinkContent!.status = '2'  // 思考已停止
      }
      msg.adminContent.adminText = '魔法塔繁忙，请稍后再试'
      isAnswering.value = false
    }
  })
}

深度思考流的特点 ​

用户发送 "什么是闭包？"
  │
  ▼
SSE 推送 reasoning_content tokens
  ┌─────────────────────────────┐
  │ 💭 贤者沉思 (思考中...)      │
  │ 闭包是指函数能够访问其词法    │  ← 打字机效果逐字展开
  │ 作用域中的变量...            │
  └─────────────────────────────┘
  │
  ▼
SSE 推送 content tokens
  ┌─────────────────────────────┐
  │ 闭包是 JavaScript 中一个     │  ← 思考结束后开始正式回答
  │ 重要的概念...                │
  └─────────────────────────────┘

思考面板默认展开 (isOpen: true)，用户可点击标题栏折叠/展开。

Spark Pro 流式请求 ​

端点与参数 ​

POST /api/v1/chat/completions
Authorization: Bearer {AUTH_TOKEN}
Body: {
  max_tokens: 4096,
  top_k: 4,
  temperature: 0.5,
  messages: [{ role, content }],
  model: 'generalv3',
  stream: true
}

核心实现 ​

ts
async function sendToSparkPro(userMessage: string) {
  // Spark Pro 使用不同的消息结构
  const params = {
    max_tokens: 4096,
    top_k: 4,
    temperature: 0.5,
    messages: [
      { role: 'system', content: roleContent.value },  // AI 角色设定
      { role: 'user', content: userMessage }
    ],
    model: 'generalv3',
    stream: true
  }

  allText.push({
    userText: userMessage,
    adminContent: { adminText: '', isShow: true }
  })

  ctrl.value = new AbortController()

  fetchEventSource('/api/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${AUTH_TOKEN}`
    },
    body: JSON.stringify(params),
    signal: ctrl.value.signal,
    openWhenHidden: true,

    onmessage(ev) {
      if (ev.data === '[DONE]') {
        // Spark Pro 使用 '[DONE]' 字符串标记结束
        markdownContent = ''
        isAnswering.value = false
        saveMessage()
        return
      }
      if (!ev.data) return

      const res = JSON.parse(ev.data)
      if (!res.choices?.[0]?.delta?.content) return

      markdownContent += res.choices[0].delta.content
      renderInWorker(markdownContent).then(html => {
        msg.adminContent.adminText = html
      })
    },

    onerror() {
      isAnswering.value = false
    }
  })
}

注意：Spark Pro 不支持深度思考模式，也没有 reasoning_content 字段。

DeepSeek vs Spark Pro 流对比 ​

特性DeepSeekSpark Pro
端点/aicg/deepseekMoudle/api/v1/chat/completions
认证无额外认证Bearer {token}

数据流总览 ​

用户输入
  │
  ├─→ DeepSeek 模式
  │     │
  │     ├─→ push { role: 'user', content } 到 requestContent
  │     ├─→ POST /aicg/deepseekMoudle
  │     ├─→ onmessage: reasoning_content (Reasoner)
  │     ├─→ onmessage: content tokens
  │     ├─→ Worker 渲染 HTML
  │     └─→ onclose → 保存对话
  │
  └─→ Spark Pro 模式
        │
        ├─→ 构建 { system, user } messages
        ├─→ POST /api/v1/chat/completions
        ├─→ onmessage: content tokens
        ├─→ Worker 渲染 HTML
        └─→ [DONE] → 保存对话

中断与重连 ​

中断生成 ​

用户点击停止按钮或切换模型时中断 SSE 流：

ts
const stopExport = () => {
  ctrl.value?.abort()  // 中止 SSE 连接

  // 如果正在深度思考，标记为"已停止"
  if (apiModuleId === 'deepseek-reasoner') {
    if (msg.thinkContent?.status === '1') {
      msg.thinkContent.status = '2'
    }
  }

  isAnswering.value = false
  // 保存已生成的部分内容
  saveMessage()
}

请求防并发 ​

使用 isAnswering 状态锁防止用户在回复过程中重复发送消息：

ts
if (isAnswering.value) {
  showMessage('回答中，请稍后再试', 'warning')
  return
}
isAnswering.value = true
// ... SSE 请求 ...
// onclose/onerror 中恢复: isAnswering.value = false
