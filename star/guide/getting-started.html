快速开始 ​

StarPlus 是基于 Element Plus 二次封装的游戏风格 Vue3 组件库，所有组件在 Element Plus 基础上新增了更完善的功能和炫酷的游戏 UI 风格。

特性 ​

  • 游戏风格: 暗黑主题、霓虹发光、符文角标，适合游戏管理后台
  • 功能增强: 拖拽、缩放、远程搜索、右键菜单、CSV 导出等
  • TypeScript: 完整类型定义，泛型组件支持
  • 完善的文档: VitePress 驱动，每个组件都有详细示例

前置依赖 ​

  • Vue >= 3.3
  • Element Plus >= 2.9

使用方式 ​

全局注册 ​

ts
import { createApp } from 'vue'
import StarPlus from 'star-plus'
import 'star-plus/dist/style.css'

const app = createApp(App)
app.use(StarPlus)
app.mount('#app')

按需引入 ​

vue
<script setup>
import { StarTable, StarDialog } from 'star-plus'
</script>

<template>
  <StarTable :data="list" :columns="cols" />
</template>
